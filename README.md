# 🏺 ZenGullak (धन)
> **7 Japanese Wealth Secrets Adapted for Indian Families, Youth & Children**

ZenGullak is a tactile, Apple-style wealth mindfulness Progressive Web App (PWA) inspired by the ancient philosophy of **Kakeibo (家計簿)**, **Kaizen (改善)**, **Arigato Money (ありがとう)**, and **Mottainai (勿体無い)**, tailored specifically for the Indian financial reality.

It replaces stressful accounting spreadsheets and invisible UPI money leaks with tactile physical cash interactions—featuring authentic **RBI banknotes**, **metallic coins**, a **handcrafted terracotta clay Gullak** with 3D flying money physics, an **impulse purchase freezer**, and a mindful **spending ledger (Hisab)**.

---

## 🌟 Key Pillars & Features

### 1. 🏺 Handcrafted Terracotta Earthen Gullak (मिट्टी का गुल्लक)
* **3D Trajectory Money Drop**: Tapping any coin (₹20, ₹10, ₹5) or banknote (₹500, ₹100, ₹50, ₹20) on the bottom tray launches the physical money into a dynamic 3D parabolic flight path, slicing cleanly into the ceramic slot.
* **Physics & Sound Effects**: Earthen pot squish-and-stretch wobble (`animate-pot-impact`), golden slot sparks burst, zero-latency metallic clinks, and floating `+₹` gain rewards.
* **Reset Option**: 1-click `Reset ↺` button to empty the Gullak back to ₹0 when a target is completed.
* **Parent Match Bonus**: Parents can match child savings with a single tap (`+₹50 Match`).

### 2. 📋 Hisab & Khata (खर्च का हिसाब • Kakeibo Ledger)
* **Real Transaction History**: View every logged expense with date, time, category badge, and denomination.
* **Smart Next Month Saving Advisor**: Identifies high spending in *Mauj/Wants* (Swiggy, dining out) and *Chhutta Leaks* (small impulse spends under ₹100), delivering actionable saving advice for the next month.
* **4 Kakeibo Pillars**: Visual breakdown comparing actual spending against the ideal ratio:
  - 🏠 **Needs (Zaroorat)** — 50%
  - 🎈 **Wants (Mauj)** — 20%
  - 📚 **Culture & Growth (Gyaan)** — 15%
  - 🛡️ **Unexpected (Achanak)** — 15%
* **Direct Add & Reset**: Quick "+ Add Spend" drawer and month reset button.

### 3. 💵 Real Indian Currency (RBI Official Specifications)
* **Banknotes (Mahatma Gandhi New Series)**:
  - Landscape format for ₹500, ₹200, ₹100, ₹50, ₹20, and ₹10.
  - Micro-details: Intaglio guilloche patterns, Mahatma Gandhi spectacles portrait, Ashoka Lion Capital watermark, holographic windowed security thread, ascending serial numbering, and Swachh Bharat emblem.
* **Metallic Coins**:
  - ₹20 (12-sided dodecagon bimetallic coin), ₹10 (radiating bimetallic coin), ₹5 (heavy brass), and ₹2/₹1 (stainless steel).
  - Raised 3D rim, reeding ridges, Ashoka Lion emblem, and flanking wheat sprigs.

### 4. 🧊 Mottainai 24-Hour Impulse Icebox
* Paste product URLs or upload shopping cart screenshots from Amazon, Flipkart, Myntra, or Swiggy.
* Locks the purchase inside a realistic **3D Ice Cube** with optical refraction for 24 hours to prevent buyer's remorse.

### 5. 🎬 Kaizen Reels (改善)
* 9:16 vertical video feed designed for 30-second daily micro-habits.
* Full-bleed cinematic backgrounds, audio ticker, and 1-tap action rail.

### 6. 🌸 Living Kalpavriksha (Wisdom Tree)
* 3D Bonsai tree that blooms Parijat petals as you maintain your financial peace streak.
* **Strict 1-Streak-Per-Day Rule**: Check in once daily with a 5-second mindful vibe seal:
  - 🌿 *Bachat Day* (₹0 spent / cooked at home)
  - ☀️ *Santulit* (planned normal)
  - 💖 *Kharchila* (honest admission)

### 7. 👨‍👩‍👧 3 Dedicated Financial Personas (Zero Clutter)
* **Parent Mode**: Household salary, ration, home loan EMI, school fees, and emergency buffers.
* **Youth / College Mode (18–24)**: Monthly stipend, canteen, metro pass, and food delivery freezer.
* **Child Mode (5–12)**: Monthly pocket money, piggy bank coins, and dream toy savings goal.

## 🛠️ Tech Stack & Design Architecture

* **Framework**: React 19 + Vite 8
* **Styling**: Tailwind CSS v4 + Apple iOS Design Tokens (Continuous squircle corners, frosted glass vibrancy, OLED midnight background, native iOS bottom dock)
* **Design Engineering**: Emil Kowalski micro-interaction physics & sound synthesis (Web Audio API)
* **Icons**: Lucide React
* **Effects**: Canvas Confetti

## 🚀 Getting Started

### Prerequisites
* Node.js (v18+)
* npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/raviattrash-pro/zengullak-.git
cd zengullak-

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production
```bash
npm run build
```
